**Descripción**

Desarrollo de la práctica TP1, consistente en la implementación de una versión del juego Lemmings en Java, 
aplicando principios de programación orientada a objetos  y una arquitectura MVC (modelo, vista y controlador).

**Implementación del juego**

Se incluyen funcionalidades como la gestión del tablero, movimiento de los lemmings, colisiones, 
interacciones con objetos y condiciones de victoria y derrota.
También existe un sistema de roles y para controlar a los lemmings se realizará mediante comandos por
consola.
Por último, se ha trabajado también el tratamiento de errores relacionados con comandos, posiciones, 
roles y archivos de configuración.

Para realizar la documentación extensa del juego, se ha usado javadoc.
